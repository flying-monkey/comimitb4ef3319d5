## 1. 产品概述

音频剪辑器是一款基于浏览器的专业音频编辑工具，面向内容创作者、播客制作人、音乐爱好者和视频编辑人员，提供零门槛的音频剪辑体验。用户无需安装任何桌面软件，即可在浏览器中完成音频上传、波形可视化预览、精确片段选择与剪切、播放控制以及剪辑后音频导出下载等完整工作流。

- 解决问题：降低音频剪辑门槛，提供直观的波形可视化操作界面，替代复杂的专业音频软件
- 目标用户：播客制作人、短视频创作者、音乐爱好者、语言学习者等需要快速剪辑音频的用户

## 2. 核心功能

### 2.1 用户角色

| 角色 | 说明 |
|------|------|
| 普通用户 | 无需注册，直接使用所有音频剪辑功能 |

### 2.2 功能模块

1. **主页面**：音频上传区、波形可视化区、播放控制区、剪辑操作区、导出下载区

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 主页面 | 音频上传 | 支持MP3/WAV/OGG/FLAC等常见格式拖拽或点击上传，文件大小限制提示 |
| 主页面 | 波形可视化 | 使用wavesurfer.js渲染音频波形，支持缩放与滚动浏览，实时显示播放进度 |
| 主页面 | 区域选择 | 通过鼠标拖拽在波形上选择音频片段，显示起止时间与选中时长 |
| 主页面 | 播放控制 | 播放/暂停/停止按钮，播放速度调节(0.5x-2x)，音量控制，进度条拖拽跳转 |
| 主页面 | 剪辑操作 | 提取选中区域、删除选中区域、撤销操作，实时反馈剪辑结果 |
| 主页面 | 导出下载 | 选择导出格式(WAV/MP3)，设置文件名，一键下载剪辑后的音频文件 |

## 3. 核心流程

用户打开应用 → 上传音频文件 → 系统解析并渲染波形 → 用户预览播放音频 → 拖拽选择目标片段 → 执行剪辑操作（提取/删除）→ 预览剪辑结果 → 导出下载最终文件

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深蓝紫渐变(#1a1a2e → #16213e)配亮蓝accent(#00d4ff)，营造专业音频工作站氛围
- 辅助色：波形区域使用渐变色(#00d4ff → #7b2ff7)，选中区域使用半透明橙色高亮
- 按钮风格：圆角按钮，hover时微发光效果，accent色主按钮 + 描边次按钮
- 字体：标题使用 JetBrains Mono（等宽科技感），正文使用 Noto Sans SC
- 布局风格：单页面垂直布局，顶部工具栏 + 中央波形区 + 底部控制面板
- 图标风格：线性图标，与Element Plus图标体系一致

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 主页面 | 音频上传区 | 虚线边框拖拽区域，上传图标，文件格式提示文字，渐变背景 |
| 主页面 | 波形可视化区 | 全宽波形画布，时间轴刻度，播放指针动画，区域高亮覆盖层 |
| 主页面 | 播放控制栏 | 圆形播放按钮，进度条滑块，时间显示，速度/音量下拉控制 |
| 主页面 | 剪辑工具栏 | 提取/删除/撤销按钮组，选中时间范围显示，波形缩放滑块 |
| 主页面 | 导出面板 | 格式选择下拉，文件名输入框，下载按钮，导出状态提示 |

### 4.3 响应式设计

- 桌面优先设计，适配 ≥ 1024px 宽屏显示
- 平板端(768px-1024px)：波形区自适应宽度，控制按钮适当缩小
- 移动端(< 768px)：垂直堆叠布局，波形区全宽，控制栏紧凑排列，触控优化按钮尺寸
