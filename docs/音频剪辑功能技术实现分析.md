## 1. 项目概述

### 1.1 项目简介

本项目是一个**纯浏览器端音频剪辑器**，所有音频处理均在用户本地完成，无需上传到服务器。基于 Vue 3 + TypeScript + WaveSurfer.js 技术栈构建，提供了直观的波形可视化界面，支持音频上传、选区剪辑、淡入淡出效果、导出下载等核心功能。

### 1.2 技术栈

| 技术 | 版本 | 用途 |
|------|------|------|
| Vue | 3.4.15 | 前端框架 |
| TypeScript | 5.3.3 | 类型安全 |
| Pinia | 2.3.0 | 状态管理 |
| WaveSurfer.js | 7.9.0 | 音频波形可视化与播放控制 |
| Element Plus | 2.9.1 | UI 组件库 |
| Tailwind CSS | 3.4.1 | 样式框架 |
| Vite | 5.0.12 | 构建工具 |

### 1.3 核心功能

- ✅ 音频文件上传（支持拖拽和点击选择）
- ✅ 波形可视化展示
- ✅ 拖拽选择剪辑区域
- ✅ 提取选区 / 删除选区
- ✅ 淡入淡出效果（可调节时长）
- ✅ 播放试听（含淡入淡出效果）
- ✅ 撤销操作
- ✅ 播放控制（播放/暂停/停止/快进/快退/进度跳转）
- ✅ 音量调节 / 播放速度调节
- ✅ 波形缩放
- ✅ 导出 WAV 格式音频

### 2.1 架构分层

```
│  HomePage.vue · AudioUploader.vue · WaveformDisplay  │

│               Store 状态层                           │
```

### 2.2 设计原则

1. **关注点分离**：UI 组件只负责展示和用户交互，业务逻辑封装在 Composables 中
2. **状态集中管理**：所有音频相关状态集中在 Pinia Store，便于跨组件共享
3. **响应式驱动**：利用 Vue 的响应式系统，状态变化自动驱动 UI 更新
4. **本地优先**：所有音频处理在浏览器端完成，保护用户隐私
5. **渐进增强**：核心功能可用基础实现，高级功能（如淡入淡出）可选开启

## 4. 核心算法原理

### 4.1 音频区域提取算法

**函数**：`extractRegion()` 在 [useAudioClipper.ts#L54-L73](file:///e:/code/solo/1/src/composables/useAudioClipper.ts#L54-L73)

**原理**：
1. 将时间点转换为采样点：`startSample = Math.floor(start * sampleRate)`
2. 创建新的 AudioBuffer，长度为选区对应的采样点数
3. 按声道逐个复制原始音频数据

```typescript
for (let ch = 0; ch < numChannels; ch++) {
  const sourceData = audioBuffer.getChannelData(ch)
  const targetData = newBuffer.getChannelData(ch)
  for (let i = 0; i < newLength; i++) {
    targetData[i] = sourceData[startSample + i]
  }
}
```

### 4.2 音频区域删除算法

**函数**：`removeRegion()` 在 [useAudioClipper.ts#L75-L104](file:///e:/code/solo/1/src/composables/useAudioClipper.ts#L75-L104)

**原理**：
1. 计算新音频长度 = 原长度 - 选区长度
2. 分两段复制：选区前的数据 + 选区后的数据
3. 边界处理：如果删除后长度 <= 0，返回一个最小长度的空 buffer

### 4.3 淡入淡出应用算法

**函数**：`applyFadeInOut()` 在 [useAudioClipper.ts#L110-L150](file:///e:/code/solo/1/src/composables/useAudioClipper.ts#L110-L150)

**缓动函数**：`easeInOutSine()` 在 [useAudioClipper.ts#L106-L108](file:///e:/code/solo/1/src/composables/useAudioClipper.ts#L106-L108)

```typescript
function easeInOutSine(t: number): number {
  return 0.5 * (1 - Math.cos(Math.PI * t))
}
```

**原理**：
- **淡入**：前 N 个采样点，增益从 0 正弦缓动到 1
- **淡出**：后 N 个采样点，增益从 1 正弦缓动到 0
- 同时应用淡入淡出时，取两者的较小值（使用 `Math.min(gain, fadeOutGain)`）

**优势**：
- 正弦缓动曲线相比线性渐变，听觉更自然，不会有突兀的音量变化
- 避免了线性渐变在起始和结束点的"硬转折"

### 4.4 WAV 编码算法

**函数**：`encodeWAV()` 在 [useAudioClipper.ts#L3-L52](file:///e:/code/solo/1/src/composables/useAudioClipper.ts#L3-L52)

**WAV 文件结构**：
1. **RIFF 头** (12字节)：标识 + 文件大小 + WAVE 标识
2. **fmt 块** (24字节)：格式、声道数、采样率、位深度等
3. **data 块** (8字节 + 音频数据)：数据标识 + 数据大小 + PCM 采样数据

**PCM 编码**：
- Float32 (-1.0 ~ 1.0) 转换为 16位整数
- 正数：`sample * 0x7FFF` (32767)
- 负数：`sample * 0x8000` (-32768)
- 小端序存储（`view.setInt16(offset, intSample, true)`）

### 4.5 实时播放淡入淡出算法

**函数**：`startRegionFadeLoop()` 在 [useWaveSurfer.ts#L195-L237](file:///e:/code/solo/1/src/composables/useWaveSurfer.ts#L195-L237)

**原理**：
1. 使用 `requestAnimationFrame` 创建高优先级循环（约 60fps）
2. 每一帧计算当前播放位置在选区内的相对位置
3. 根据淡入淡出参数计算当前增益值
4. 实时调整 WaveSurfer 的音量：`volume = originalVolume * gain`

**状态管理**：
- `regionPlayInfo` 对象跟踪区域播放状态
- 暂停时停止循环但保留状态，恢复播放时自动重启循环
- 跳转进度时重新计算增益

## 7. 关键代码片段解析

### 7.1 淡入淡出试听的循环实现

**位置**：[useWaveSurfer.ts#L195-L237](file:///e:/code/solo/1/src/composables/useWaveSurfer.ts#L195-L237)

```typescript
function startRegionFadeLoop() {
  if (!regionPlayInfo || !regionPlayInfo.isActive) return
  stopFadeLoop()

  const { start, end, fadeIn, fadeOut } = regionPlayInfo

  function tick() {
    if (!wavesurfer || !regionPlayInfo || !regionPlayInfo.isActive) {
      stopFadeLoop()
      return
    }
    if (!store.isPlaying) {
      stopFadeLoop()
      return
    }

    const currentTime = wavesurfer.getCurrentTime()

    if (currentTime >= end - 0.001) {
      stopFadeLoop()
      wavesurfer.setVolume(0)
      return
    }

    const gain = calculateRegionGain(currentTime, start, end, fadeIn, fadeOut)
    wavesurfer.setVolume(originalVolume * gain)

    fadeLoopId = requestAnimationFrame(tick)
  }

  fadeLoopId = requestAnimationFrame(tick)
}
```

**解析**：
- 使用 `requestAnimationFrame` 确保平滑的 60fps 更新
- 多重安全检查：实例有效性、播放状态、区域有效性
- 结束前 1ms 提前将音量设为 0，避免播放结束时的"咔哒"声
- 每帧调用 `calculateRegionGain()` 计算当前增益

### 7.2 增益计算函数

**位置**：[useWaveSurfer.ts#L164-L198](file:///e:/code/solo/1/src/composables/useWaveSurfer.ts#L164-L198)

```typescript
function calculateRegionGain(
  currentTime: number,
  start: number,
  end: number,
  fadeIn: number,
  fadeOut: number
): number {
  const positionInRegion = currentTime - start
  const regionDuration = end - start

  let gain = 1

  if (fadeIn > 0 && positionInRegion < fadeIn) {
    const t = positionInRegion / fadeIn
    gain = easeInOutSine(t)
  }

  if (fadeOut > 0 && positionInRegion > regionDuration - fadeOut) {
    const fadeOutPosition = positionInRegion - (regionDuration - fadeOut)
    const t = fadeOutPosition / fadeOut
    const fadeOutGain = 1 - easeInOutSine(t)
    gain = Math.min(gain, fadeOutGain)
  }

  return Math.max(0, Math.min(1, gain))
}
```

**解析**：
- 纯函数，无副作用，便于测试和复用
- 使用 `Math.min(gain, fadeOutGain)` 处理淡入淡出重叠的情况
- 最终通过 `Math.max(0, Math.min(1, gain))` 确保增益在有效范围内
- 与裁剪导出时使用完全相同的算法，保证试听与导出效果一致

### 7.3 智能播放/暂停切换

**位置**：[useWaveSurfer.ts#L265-L283](file:///e:/code/solo/1/src/composables/useWaveSurfer.ts#L265-L283)

```typescript
function playPause() {
  if (!wavesurfer) return

  if (store.isPlaying) {
    pause()
  } else {
    if (regionPlayInfo && regionPlayInfo.isActive) {
      wavesurfer.play()
      startRegionFadeLoop()
    } else {
      play()
```

**解析**：
- 检查 `regionPlayInfo.isActive` 判断是否处于区域播放模式
- 区域播放模式下暂停后恢复，自动重启淡化循环
- 普通播放模式下直接调用 `play()`，会重置区域播放状态

### 7.4 区域播放时的音量调节

**位置**：[useWaveSurfer.ts#L314-L330](file:///e:/code/solo/1/src/composables/useWaveSurfer.ts#L314-L330)

```typescript
function setVolume(vol: number) {
  store.volume = vol
  originalVolume = vol
  if (!wavesurfer) return

  if (regionPlayInfo && regionPlayInfo.isActive && store.isPlaying) {
    const { start, end, fadeIn, fadeOut } = regionPlayInfo
    const currentTime = wavesurfer.getCurrentTime()
    if (currentTime >= start && currentTime <= end) {
      const gain = calculateRegionGain(currentTime, start, end, fadeIn, fadeOut)
      wavesurfer.setVolume(vol * gain)
      return
    }
  }

  wavesurfer.setVolume(vol)
}
```

**解析**：
- 区域播放时调节音量，需要重新计算当前增益
- 确保新音量乘以当前位置的增益系数
- 不在区域内时直接设置音量

### 7.5 安全的淡入淡出时长计算

**位置**：[useAudioClipper.ts#L164-L170](file:///e:/code/solo/1/src/composables/useAudioClipper.ts#L164-L170)

```typescript
if (store.fadeInDuration > 0 || store.fadeOutDuration > 0) {
  const halfDuration = (end - start) / 2
  const safeFadeIn = Math.min(store.fadeInDuration, halfDuration)
  const safeFadeOut = Math.min(store.fadeOutDuration, halfDuration)
  newBuffer = applyFadeInOut(newBuffer, safeFadeIn, safeFadeOut)
}
```

**解析**：
- 关键边界处理：淡入淡出时长总和不能超过选区时长
- 使用 `Math.min()` 确保每个淡入/淡出时长不超过选区的一半
- 避免淡入淡出重叠导致中间音量过低

## 8. 技术难点与解决方案

### 难点 1：试听效果与导出效果不一致

**问题**：
- 试听时的淡入淡出是实时调整音量
- 导出时的淡入淡出是修改音频采样数据
- 如果两者算法不一致，用户听到的和实际导出的会有差异

**解决方案**：
- 抽象出统一的 `easeInOutSine()` 缓动函数
- 抽象出统一的 `calculateRegionGain()` 增益计算函数
- 试听和导出复用完全相同的计算逻辑
- 在 UI 上提供明确的提示，说明淡入淡出会应用于裁剪和导出

### 难点 2：区域播放时的状态管理

**问题**：
- 暂停后继续播放需要保持淡入淡出状态
- 跳转进度时需要重新计算增益
- 切换到普通播放时需要清除区域状态
- 多个操作（暂停、停止、跳转、调节音量）可能并发发生

**解决方案**：
- 引入 `regionPlayInfo` 状态对象，统一管理区域播放信息
- 每个操作入口检查并正确处理区域播放状态
- `playPause()` 智能判断是否恢复区域淡化模式
- `seekTo()` 和 `setVolume()` 在区域播放时特殊处理
- `resetRegionPlay()` 统一处理状态清理

### 难点 3：播放结束时的"咔哒"声

**问题**：
- 当播放到选区结束点时，如果此时音量不为 0，会产生突兀的"咔哒"声
- 这是因为音频波形突然截断导致的

**解决方案**：
- 在 `startRegionFadeLoop()` 中，当 `currentTime >= end - 0.001` 时，提前将音量设为 0
- 结合淡出效果，确保播放结束时音量平滑过渡到 0
- 导出时也应用相同的淡出效果，保证一致性

### 难点 4：淡入淡出时长超过选区时长

**问题**：
- 用户可能设置的淡入淡出时长总和超过选区时长
- 这会导致淡入还没完成就开始淡出，中间音量过低

**解决方案**：
- 在 `extractSelection()` 和 `exportSelection()` 中添加安全检查
- 淡入淡出时长分别不超过选区时长的一半
- 在 UI 上显示警告提示："选区时长较短，淡入淡出将自动适配"
- 在 `playRegionWithFade()` 中也应用相同的安全限制

### 难点 5：历史记录与淡入淡出的关系

**问题**：
- 撤销操作时，是否应该同时恢复淡入淡出设置？

**解决方案**：
- 淡入淡出是参数设置，不是操作结果，不随撤销而改变
- 历史记录只保存 `AudioBuffer`，不保存参数状态
- 这样用户可以尝试不同的淡入淡出参数，撤销的是剪辑操作，不是参数调整

### 难点 6：requestAnimationFrame 循环的生命周期管理

**问题**：
- 循环未正确停止会导致内存泄漏和性能问题
- 组件卸载、停止播放、切换模式等场景都需要停止循环

**解决方案**：
- 统一的 `stopFadeLoop()` 函数处理循环停止
- 在 `pause()`、`stop()`、`finish` 事件、`destroy()` 等多个入口调用
- 使用 `resetRegionPlay()` 统一清理状态
- `onUnmounted` 钩子中调用 `destroy()` 确保资源释放
